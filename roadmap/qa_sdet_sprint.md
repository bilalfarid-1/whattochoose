The **60-Day QA & SDET Engineering Sprint** is an industry-aligned test engineering and test automation curriculum. It transforms manual testers, QA beginners, and software graduates into job-ready **Quality Assurance Engineers** and **Software Development Engineers in Test (SDETs)**.

Rather than testing toy forms or mock servers, you test the real **[JobPulse Backend Platform](../backend)** as your **System Under Test (SUT)**. You will execute functional tests, discover edge cases, write automated API and UI suites, audit security access controls (BOLA/BFLA), and build verifiable CI/CD test automation pipelines.

---

## 📅 The 2-Phase Curriculum Structure

```
+---------------------------------------------------------------------------------------------------------+
|                               THE 60-DAY QA & SDET SPRINT CURRICULUM                                     |
+----------------------------------------------------+----------------------------------------------------+
| PHASE 1: CORE QA & AUTOMATION (Days 1–30)          | PHASE 2: ADVANCED SDET & SECURITY (Days 31–60)     |
+----------------------------------------------------+----------------------------------------------------+
| • Software Testing Lifecycle (STLC) & Test Strategy| • Playwright Page Object Model (POM) Architecture  |
| • Boundary Value Analysis (BVA) & Partitioning     | • Multi-user authorization & BOLA vulnerability lab|
| • Postman collections, environments, & test scripts| • State-space matrix & data-driven API automation  |
| • Newman CLI runs & automated HTML reporting       | • Schema fuzzing & property-based negative tests   |
| • Python `pytest` & `requests` API test suites     | • Concurrency, race conditions & db isolation tests|
| • PostgreSQL DB verification & SQL state assertions| • GitHub Actions CI/CD matrix integration          |
| • Playwright UI automation & element locators      | • Synthetic test data seeding & tear-down scripts  |
| • 80-Case Manual Test Matrix + 5 Defect Reports    | • Public GitHub portfolio & 35-question tech prep  |
+----------------------------------------------------+----------------------------------------------------+
```
