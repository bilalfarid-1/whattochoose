The **30-Day Python Backend Engineering Sprint** is an active-learning engineering curriculum designed to take a developer from basic syntax to a defensible, production-grade backend engineer.

Instead of passively copying tutorials, you use **active cognitive protocols** (Socratic decomposition, adversarial code reviews, and mutation drills) to build, test, and deploy the **[JobPulse Platform](../backend)**.

---

## 📅 The 4-Phase Curriculum Structure

```
+---------------------------------------------------------------------------------------------------------+
|                              THE 30-DAY BACKEND SPRINT CURRICULUM                                        |
+-----------------------------+-----------------------------+-----------------------+---------------------+
| PHASE 1: HTTP & FastAPI     | PHASE 2: Databases & ORM    | PHASE 3: Auth & Logic | PHASE 4: CI/CD &    |
| (Days 1–7)                  | (Days 8–14)                 | (Days 15–21)          | Defense (Days 22–30)|
+-----------------------------+-----------------------------+-----------------------+---------------------+
| • Modern Python typing      | • Relational schema design  | • JWT & Bcrypt auth   | • Docker containers |
| • FastAPI route handlers    | • SQLAlchemy 2.0 ORM        | • Multi-tenant RBAC   | • Pytest unit suites|
| • Pydantic v2 schemas       | • Foreign keys & cascades   | • 404 security model  | • CI GitHub Actions |
| • Request validation        | • Alembic migrations        | • Funnel analytics    | • Live code defense |
| • REST status codes         | • Transaction isolation     | • Journal notes CRUD  | • Portfolio README  |
| • DSA: Arrays & Hash Maps   | • DSA: Two-Pointers/Sliding | • DSA: Trees & Graphs | • DSA: DP & Heaps   |
+-----------------------------+-----------------------------+-----------------------+---------------------+
```
