# Longitudinal Empirical Datasets: Software Engineering Labor Market (2020 - 2026)

This directory contains the primary and harmonized empirical datasets used to evaluate the evolution of software engineering labor markets across the Pre-GenAI, Disruption, and Agentic eras.

## Data Provenance & Primary Source Audit
For full, line-by-line verification, survey question IDs, institutional URLs, and methodology notes, refer to:
👉 [**SOURCES.md**](./SOURCES.md)

## Directory Contents

* **`SOURCES.md`**: Complete, line-by-line data provenance, official source URLs, report section references, and methodological notes.
* **`raw/longitudinal_se_data.json`**: Machine-readable JSON containing multi-era data points with embedded citation annotations.
* **`processed/time_series_metrics_2020_2026.csv`**: Normalized longitudinal time-series data generated by `src/analyze_market_dynamics.py`.
* **`processed/skills_lifecycle_metrics.csv`**: Skills demand and obsolescence scores (0-100 scale).
