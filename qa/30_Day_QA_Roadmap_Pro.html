JobPulse System Under Test (SUT) Operational Contract

All 20 business operations exposed across 13 business path templates in the JobPulse FastAPI backend (backend/app/main.py).

Module HTTP Method Endpoint Path Auth Req Business Operation & Expected Behavior
System GET / None Root welcome ping with API name and version status.
GET /health None Liveness probe returning {"status": "ok"}.
Auth POST /api/v1/auth/register None Creates new candidate account. Enforces unique email and password hash.
POST /api/v1/auth/token Form-Data OAuth2 password request returning Bearer JWT token.
Jobs GET /api/v1/jobs/ None Listings catalog with search, department filtering, and pagination.
POST /api/v1/jobs/ Bearer Recruiter/Admin endpoint to create job openings.
GET /api/v1/jobs/{job_id} None Detailed single job description and active state.
DELETE /api/v1/jobs/{job_id} Bearer Removes job opening. Cascade deletes child applications.
Applications GET /api/v1/applications/ Bearer Multi-tenant query returning only the logged-in user's applications.
POST /api/v1/applications/ Bearer Submits candidate application. Enforces stage validation rules.
GET /api/v1/applications/{id} Bearer Single application fetch. Returns 404 for cross-tenant access (BOLA protection).
PATCH /api/v1/applications/{id}/stage Bearer Transitions candidate workflow stage (Applied -> Interview -> Offer/Rejected).
DELETE /api/v1/applications/{id} Bearer Deletes user's application and cascaded notes.
Interviews GET /api/v1/applications/{id}/interviews Bearer Lists scheduled interview rounds for target application.
POST /api/v1/applications/{id}/interviews Bearer Schedules technical or HR interview with datetime validation.
PATCH /api/v1/interviews/{interview_id} Bearer Updates feedback, interviewer notes, or completion status.
Notes GET /api/v1/applications/{id}/notes Bearer Retrieves timestamped journal entries for an application.
POST /api/v1/applications/{id}/notes Bearer Creates markdown note attached to user's application.
Analytics GET /api/v1/analytics/ Bearer Aggregates user application metrics, funnel conversion rates, and stage counts.

AI Mentor Studio: How to Pair with /qa-sprint

Learn how this HTML dashboard and the /qa-sprint Antigravity skill work together seamlessly.

1. How to Trigger in Chat

Start any session in any chat window:

  • Type /qa-sprint or simply say "Let's do QA Sprint Day [X]".
  • Or click any of the 3 copy buttons on a day card to copy a pre-formatted prompt.
  • The AI immediately pulls today's objectives, SUT constraints, and 4-hour schedule.
2. The 3 Prompt Action Buttons

Tailored action triggers on every single day card:

  • Kickoff Prompt: Primes today's concepts, reviews SUT endpoints, and outlines the 4-hour timeline.
  • Deliverable Audit Prompt: Prompts the AI to act as a Lead SDET to strictly review your written code/tests.
  • Interview Drill Prompt: Triggers 3 targeted oral interview questions from the handbook to test your verbal defense.
3. Subtasks & Progress Sync

Synchronized tracking across browser and chat:

  • Each day card features 5 checkboxes: Learn, Practice, Build, Explain, Commit.
  • When you complete a block with the AI, check it off in the HTML card.
  • Checking all 5 subtasks automatically marks the day completed!
  • Click Export Backup periodically to preserve your JSON state.
