# Longitudinal Empirical Datasets: Software Engineering Labor Market (2020 - 2026)

This repository contains the verified historical and contemporary datasets tracking:
1. Global developer trends & skills (Stack Overflow Annual Developer Surveys 2020-2025/2026).
2. AI coding benchmark capabilities (Stanford HAI AI Index, HumanEval, SWE-bench, SWE-bench Verified).
3. Regional Pakistan IT industry revenue, export remittances, and workforce dynamics (P@SHA, State Bank of Pakistan).
4. Tech hiring ratios, entry-level vs senior vacancy distribution, and tech layoffs (US BLS, CompTIA, Layoffs.fyi).
